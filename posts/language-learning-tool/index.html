Personalized language learning tool

August 16, 2026

I want to learn German. I want to build something to help me learn. But 2026 is the year of hyper personalized software.

I built this tool to help me read sentences. I have been getting more into UI/UX design since I don’t have to do the coding part myself nowadays (thanks Claude).

It’s supposed to be dead simple. Paste your text, try to read it yourself. If you don’t have something to go off of. You can generate something by choosing a level you’re at.

Then try to read these sentences, if you’re comfortable, you’re ok. If you’re not you can just click it and a sidepanel opens up, where you can listen to TTS, see the meaning for each words context, and even continue the chat with the LLM. I think this is one of those usecases where LLMs really are great.

Much more to do, but that is on a need basis. I can see flagging words/phrases and turning them into flashcards to be helpful next. More power to personalized software!

I’m too API KEY poor to host this publicly and the screenshot explains it all.
