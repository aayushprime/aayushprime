{{- /* Bundles assets/js/graph/index.js and its d3-force import. Hugo extended ships esbuild, so js.Build resolves the bare `d3-force` specifier out of node_modules — the same npm install CI already runs for Tailwind. Only the force maths is pulled in; pan, zoom, drag and rendering are hand-written, which keeps d3-selection and d3-zoom out of the bundle.
